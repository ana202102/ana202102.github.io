# 鏡面成像互動模擬

開啟 `index.html` 可進入實驗首頁，並選擇七種鏡面、透鏡與光學定律模擬。在成像模擬畫面中可拖曳紅色物體調整物距，並以右側滑桿調整物高；像的位置、大小與數據會即時更新。鏡面與光學定律各有獨立頁面：

- `plane-mirror.html`
- `concave-mirror.html`
- `convex-mirror.html`
- `reflection-law.html`
- `refraction-law.html`
- `convex-lens.html`
- `concave-lens.html`

頁面以 HTML Canvas 與 JavaScript 繪製，不需要安裝 Flash 或其他套件，也不需網路連線。
