# 互動光學實驗室｜工作交接

## 專案目的

以 HTML、CSS 與 JavaScript 重製原有 Flash 光學示範，提供可調整參數的互動成像與光線模擬。網站部署於 GitHub Pages：

- 網站首頁：<https://ana202102.github.io/optics/>
- GitHub 專案：<https://github.com/ana202102/ana202102.github.io/tree/main/optics>

## 頁面一覽

| 頁面檔案 | 模擬內容 |
| --- | --- |
| `index.html` | 實驗首頁與各模擬頁入口 |
| `plane-mirror.html` | 平面鏡成像；物距等於像距 |
| `concave-mirror.html` | 凹面鏡成像；可觀察倒立縮小、倒立放大、正立放大虛像 |
| `convex-mirror.html` | 凸面鏡成像 |
| `convex-lens.html` | 凸透鏡成像；含快速成像情境按鈕 |
| `concave-lens.html` | 凹透鏡成像；鏡片上下對稱 |
| `reflection-law.html` | 反射定律；上半圓量角器，可調入射角並顯示相關角度 |
| `refraction-law.html` | 折射定律；可調入射角及兩側介質，包含全反射情況 |
| `rgb-primary.html` | 光的三原色；可調紅、綠、藍光強度，觀察加法混色 |

## 共用程式

- `optics.js`：依頁面上的 `body[data-mode]` 選擇模擬模式，使用 Canvas 繪製光線、物像、鏡片／鏡面、量角器及數據。參數變更時即時重繪。
- `optics.css`：共用版面、響應式排版、控制面板與明暗主題樣式。
- `theme.js`：明暗模式切換及主題狀態同步。
- `rgb-primary.js`：光的三原色頁面專用繪圖、RGB 強度控制、預設色光與色碼顯示。
- `README.md`：專案簡介與頁面列表。

## 操作與物理模型

- 成像頁右側控制面板可調物距、物高及適用的焦距。物體可在畫布拖曳以調整物距；物高由右側參數滑桿調整，不透過拖曳物體高度來改變。
- 平面鏡像為正立等大虛像，物距與像距相等。
- 凹面鏡與凸透鏡依薄透鏡／球面鏡公式更新像距與放大率，並判斷正立或倒立、實像或虛像及縮放狀態。
- 凹透鏡為上下對稱外形，形成正立縮小虛像。
- 反射定律頁只保留量角器上半圓；刻度角度以法線為基準，入射角與反射角相等。
- 折射定律依史涅耳定律計算折射角；入射光角度可用滑桿或拖曳入射光端點調整。
- 各模擬頁都可切換明暗模式。光線動畫、光線顯示開關及重設按鈕由共用程式提供。
- 光的三原色頁以 Canvas 的加法混色繪製紅、綠、藍色光疊加；三個色圈可在畫面上分別拖曳，右側滑桿可調整各色光強度，並顯示 RGB 數值與十六進位色碼。首頁上方導覽列含有「光的三原色」連結。主題切換會同步影響頁面文字和控制介面，色光視窗維持深色以呈現發光效果。

## 後續更新方式

1. 修改對應的 HTML、`optics.css`、`theme.js`、`optics.js` 或 `rgb-primary.js`。
2. 確認頁面載入的共用 CSS／JavaScript 檔名及相對路徑正確；模擬頁的 `data-mode` 必須與 `optics.js` 使用的模式名稱相符。
3. 將變更同步至 `ana202102/ana202102.github.io` 的 `main` 分支 `optics/` 目錄。此網站是靜態網站，無需建置或安裝套件；更新 `main` 後由 GitHub Pages 發佈。
4. 部署後開啟對應的 `https://ana202102.github.io/optics/<頁面檔名>` 確認畫面。瀏覽器或 Pages 快取可能需要重新整理才會顯示新版本。

## 同步與編碼注意事項

- 本工作目錄目前是網站 `optics/` 目錄內容的本機副本，**不是 Git repository**；需透過 GitHub 連線工具或正確的 Git checkout 更新遠端。
- JavaScript 與 HTML 含繁體中文，請以 UTF-8 儲存及上傳。上傳原始文字時使用 UTF-8；不要把已編碼的 Base64 字串當成檔案文字提交，否則瀏覽器會無法執行 JavaScript，畫布可能呈現空白。
- 更新既有 GitHub 檔案時，先讀取遠端目前版本／blob SHA，再以該版本更新，避免覆寫其他人剛提交的內容。
- 不需要修改原始 `.swf` 才能運作；目前 HTML5 模擬頁不依賴 Flash。
