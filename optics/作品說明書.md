# 互動光學實驗室｜作品說明書

**作品類型：** 網頁式互動教學模擬　　**適用對象：** 國中、高中自然科學生與教師　　**更新日期：** 2026 年 11 月

## 一、作品簡介

「互動光學實驗室」是一套以 HTML、CSS 與 JavaScript 製作的光學教學網站，將原有 Flash 示範改為可在現代瀏覽器操作的互動模擬。使用者可以調整物體位置、光線角度、透鏡或介質參數，並即時觀察光路、成像位置、方向、大小與相關數值的改變。

本作品包含 10 個主題：平面鏡、凹面鏡、凸面鏡、反射定律、折射定律、凸透鏡、凹透鏡、複式顯微鏡、針孔成像及光的三原色。內容可用於課堂演示、個人練習與光學概念複習。

## 二、啟動方式

1. 開啟 [互動光學實驗室首頁](https://ana202102.github.io/optics/)。
2. 從首頁實驗卡片或上方導覽列選擇主題。
3. 使用頁面上的滑桿、按鈕、勾選項目或畫面拖曳操作，觀察圖示與數值變化。
4. 按右上方的主題按鈕可切換淺色或暗黑模式；選擇會保存在目前瀏覽器。

網站也可直接開啟專案中的 `index.html`。針孔成像的 3D 場景使用 Three.js CDN 載入，該頁需要網路連線；其餘模擬由本機 HTML、CSS 與 JavaScript 繪製。

## 三、操作總覽

| 操作方式 | 功能 |
| --- | --- |
| 滑桿 | 調整物距、物高、焦距、角度、介質或色光強度；數值與圖形即時更新 |
| 拖曳物體 | 在支援的成像畫面中改變物距；物高使用參數滑桿調整 |
| 拖曳色圈 | 改變紅、綠、藍色光在光的三原色畫面中的重疊位置 |
| 拖曳光線端點 | 在折射定律頁調整入射方向 |
| 旋轉／縮放 3D 畫面 | 在針孔成像頁拖曳空白處旋轉視角，使用滑鼠滾輪縮放 |
| 動畫控制 | 啟動或暫停光線移動；反射與折射光點沿同一道光路連續前進 |

物體的高度只能由參數控制，不會因拖曳物體頂端而改變。各頁控制項會依該主題適用的參數顯示。

## 四、實驗主題與學習重點

### 1. 平面鏡成像

觀察正立、等大的虛像。物距等於像距；物體與像分別位於鏡面兩側。調整物距與物高，可觀察像的位置及大小如何保持對稱。

### 2. 凹面鏡成像

移動物體經過焦點與曲率中心，觀察倒立縮小實像、倒立放大實像及正立放大虛像等情況，以及實像與虛像的轉換。

### 3. 凸面鏡成像

觀察凸面鏡使反射光發散，並利用反向延長線找到像的位置。成像為正立、縮小的虛像。

### 4. 反射定律

調整入射方向，查看法線、入射角與反射角。角度以法線為基準，入射角等於反射角；量角器只顯示介面上方的半圓。

### 5. 折射定律

調整入射角及介質條件，觀察光線進入另一種介質後的方向。頁面依史涅耳定律呈現折射角，並可觀察全反射情況。

### 6. 凸透鏡成像

調整物距與焦距，觀察物體位於焦點內外時形成的正立虛像或倒立實像，以及像距和放大率的變化。頁面提供快速成像情境按鈕。

### 7. 凹透鏡成像

觀察凹透鏡使光線發散的路徑及其反向延長線。成像為正立、縮小的虛像；鏡片外形上下對稱。

### 8. 複式顯微鏡

物鏡先形成中間像，目鏡再依據中間像與目鏡的相對位置形成最後的像。可拖曳物體調整物距，並調整物高、物鏡焦距與目鏡焦距。

### 9. 針孔成像

以可旋轉的 3D 實驗台呈現發光物體、針孔板、光線與屏幕。可調物距、像距、物高、針孔直徑及字母圖樣；也可拖曳物體或屏幕、切換 3D 斜視、側視與屏幕正面視角。彩色光點沿物體到針孔、再到屏幕的光路移動。屏幕影像呈現上下顛倒、左右相反；較大的孔徑會讓影像較亮，也較容易模糊。

### 10. 光的三原色

分別拖曳紅、綠、藍色光圈，調整各色光強度，觀察加法混色結果，並查看混合後的顏色與 RGB／HEX 數值。

## 五、光學模型摘要

- 球面鏡與薄透鏡依成像公式更新像距及放大率，並判斷像的方向、虛實與大小。
- 反射以入射角等於反射角計算；折射依史涅耳定律計算，並辨識全反射條件。
- 針孔成像使用幾何投影，放大率為像距除以物距；物體各點的光線穿過小孔後交叉投射到屏幕。
- 光的三原色使用加法混色，畫面結果會隨色光位置及強度更新。
- 這些畫面是教學用的簡化模型，主要說明幾何光學關係；不代表實際器材的所有波動、像差或材料特性。

## 六、程式與檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 首頁與 10 個主題入口 |
| 各主題 HTML | 呈現對應的實驗畫面及控制項 |
| `optics.js` | 鏡面、透鏡、反射與折射等共用 Canvas 模擬 |
| `microscope.js` | 複式顯微鏡的雙透鏡光路與成像計算 |
| `pinhole-camera.js` | 針孔成像的 Three.js 3D 場景與光線動畫 |
| `rgb-primary.js` | 三原色混色、色圈拖曳及顏色數值 |
| `optics.css` | 共用版面、控制介面、響應式排版及明暗主題 |
| `theme.js` | 明暗模式切換與瀏覽器偏好保存 |
| `README.md` | 專案快速索引 |
| `HANDOFF.md` | 程式維護與後續更新交接資訊 |

原始 `.swf` 檔保留作為轉製參考；目前網站的 HTML5 模擬不依賴 Flash。

## 七、使用需求與故障排除

- 建議使用近期版本的 Chrome、Edge、Firefox 或 Safari，並開啟 JavaScript。
- 針孔成像需要可用的 WebGL 與網路連線，因 Three.js 和 OrbitControls 由 CDN 載入。若 3D 區域空白，請先確認網路可連線，再重新載入頁面。
- 更新後若仍看到舊內容，可使用瀏覽器強制重新整理，或稍候 GitHub Pages 完成發佈。
- 其餘實驗以瀏覽器 Canvas 繪製，不需安裝 Flash、外掛或額外軟體。
