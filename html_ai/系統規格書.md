# AI 深蹲挑戰助手系統規格書

## 1．文件資訊

| 項目 | 內容 |
|---|---|
| 系統名稱 | AI 深蹲挑戰助手 |
| 系統類型 | 瀏覽器端即時運動辨識遊戲 |
| 版本 | 1.0 |
| 主要語言 | 繁體中文 |
| 執行平台 | 桌上型電腦、平板、智慧型手機 |
| 主要技術 | HTML、CSS、JavaScript、MediaPipe Pose |
| 輸入設備 | 攝影機、鍵盤或觸控螢幕 |
| 輸出方式 | 畫面、音效、JPG 截圖 |

## 2．系統目的

本系統利用裝置攝影機與 MediaPipe Pose 人體姿勢模型，即時辨識使用者的下蹲與站立動作，計算深蹲次數及蹲姿維持時間，提供具遊戲化元素的運動挑戰體驗。

系統不需要後端伺服器或帳號登入，所有辨識與遊戲邏輯皆在使用者的瀏覽器中執行。

## 3．功能範圍

### 3.1 主要功能

1. 啟用攝影機並顯示即時影像。
2. 載入 MediaPipe Pose 模型，顯示「模型下載中」提示。
3. 偵測人體姿勢關鍵點並繪製人體骨架。
4. 計算左右膝蓋角度與平均膝角。
5. 判定深蹲動作並自動計數。
6. 執行三種挑戰模式。
7. 播放完成深蹲、成功與失敗音效。
8. 顯示操作說明。
9. 擷取目前畫面並下載為 JPG。
10. 支援桌面鍵盤與手機觸控操作。

### 3.2 不包含功能

1. 使用者帳號與登入。
2. 雲端成績儲存。
3. 排行榜或多人連線。
4. 運動資料匯出與歷史紀錄。
5. 醫療等級的動作安全判定。

## 4．使用者操作規格

### 4.1 桌面版快捷鍵

| 按鍵 | 功能 |
|---|---|
| `1` | 啟動簡單模式 |
| `2` | 啟動普通模式 |
| `3` | 啟動自訂模式 |
| `H` | 開啟或關閉操作說明 |
| `P` | 擷取並下載 JPG 截圖 |
| `ESC` | 重置遊戲並返回主選單 |

### 4.2 手機版操作

手機畫面底部提供觸控按鈕，功能等同於桌面快捷鍵：

- 簡單。
- 普通。
- 自訂。
- 說明。
- 截圖。
- 重置。

## 5．遊戲模式規格

### 5.1 簡單模式

- 啟動方式：按下 `1` 或點選「簡單」按鈕。
- 任務一：完成 `5` 次深蹲。
- 任務二：無。
- 完成任務一後直接判定成功。

### 5.2 普通模式

- 啟動方式：按下 `2` 或點選「普通」按鈕。
- 任務一：完成 `10` 次深蹲。
- 任務一完成後倒數 `3` 秒。
- 任務二：蹲下維持 `10` 秒。
- 任務二完成後判定成功。

### 5.3 自訂模式

- 啟動方式：按下 `3` 或點選「自訂」按鈕。
- 輸入格式：

```text
深蹲次數,支撐秒數,總限時秒數
```

- 預設值：`15,15,60`。
- 任務一：完成指定次數深蹲。
- 任務二：蹲下維持指定秒數。
- 從開始挑戰起計算總限時。
- 超過總限時則判定失敗。

## 6．姿勢辨識規格

### 6.1 使用的關鍵點

| 關鍵點編號 | 身體部位 |
|---:|---|
| `11` | 左肩 |
| `23` | 左髖 |
| `24` | 右髖 |
| `25` | 左膝 |
| `26` | 右膝 |
| `27` | 左腳踝 |
| `28` | 右腳踝 |

### 6.2 深蹲判定

1. 計算左膝角度與右膝角度。
2. 取兩側膝角平均值。
3. 平均膝角小於 `120°`，視為進入蹲姿。
4. 平均膝角大於 `160°`，視為站起。
5. 完成「蹲下 → 站起」狀態轉換時，深蹲次數增加 `1`。
6. 另以身體高度與腿部高度比例進行姿勢篩選，比例需小於 `1.2`。

### 6.3 姿勢辨識顯示

畫面顯示：

- 人體骨架連線。
- 左膝角度。
- 右膝角度。
- 目前任務、分數或倒數計時。

## 7．系統狀態流程

```text
初始化
  ↓
模型下載中
  ↓
主選單（runFlag = 0）
  ↓ 選擇難度
任務一：深蹲計數（runFlag = 1）
  ↓ 完成指定次數
倒數 3 秒（runFlag = 3）
  ↓
任務二：蹲姿計時（runFlag = 4）
  ↓ 完成或超時
結算畫面（runFlag = 5）
```

簡單模式完成任務一後直接進入結算畫面。

## 8．介面與視覺規格

1. 使用全螢幕黑色背景。
2. 攝影機畫面左右鏡射，提供照鏡子般的使用體驗。
3. 人體骨架使用綠色線條繪製。
4. 任務資訊使用高對比色彩顯示。
5. 成功訊息使用綠色，失敗訊息使用紅色。
6. 手機控制按鈕固定於畫面底部。
7. 支援 `viewport-fit=cover`，適應具瀏海或安全區域的手機。

## 9．技術規格

### 9.1 前端檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面結構、樣式、外部函式庫載入與手機控制項 |
| `script.js` | 攝影機、姿勢辨識、遊戲狀態及互動邏輯 |
| `coin.mp3` | 深蹲完成音效 |
| `win.wav` | 挑戰成功音效 |
| `lose.wav` | 挑戰失敗音效 |

### 9.2 外部依賴

- `@mediapipe/pose`。
- `@mediapipe/camera_utils`。
- `@mediapipe/drawing_utils`。
- 依賴 jsDelivr CDN 載入模型與函式庫。

### 9.3 攝影機規格

- 使用 `navigator.mediaDevices.getUserMedia()`。
- 優先使用前鏡頭：`facingMode: user`。
- 影像理想尺寸：`1280 × 720`。
- 不使用麥克風。

## 10．安全性與隱私

1. 使用者必須明確授權攝影機權限。
2. 影像只在瀏覽器端進行姿勢辨識，不上傳至應用程式後端。
3. 系統不儲存使用者影像。
4. 手機瀏覽器通常必須以 `HTTPS` 或 `localhost` 執行，才能使用攝影機。
5. 若模型或 CDN 無法連線，系統無法完成姿勢辨識。

## 11．例外處理

| 情況 | 系統行為 |
|---|---|
| 模型尚未完成載入 | 顯示「模型下載中」 |
| 使用者拒絕攝影機權限 | 顯示攝影機啟用失敗提示 |
| 未偵測到人體 | 保持畫面顯示，但不進行計數 |
| 自訂參數格式錯誤 | 使用對應欄位的預設值 |
| 自訂模式超過總限時 | 顯示挑戰失敗 |
| 使用者按下 `ESC` | 清除遊戲狀態並返回主選單 |

## 12．驗收條件

### 12.1 啟動驗收

- 開啟頁面後能顯示「模型下載中」或攝影機錯誤提示。
- 模型完成初始化後，載入提示應自動消失。
- 允許攝影機權限後能顯示即時影像與人體骨架。

### 12.2 遊戲驗收

- 簡單模式完成 `5` 次深蹲後成功。
- 普通模式完成 `10` 次深蹲，倒數 `3` 秒後進入 `10` 秒支撐任務。
- 自訂模式能正確讀取深蹲次數、支撐秒數與總限時。
- 成功與失敗時播放正確音效。

### 12.3 行動裝置驗收

- 手機畫面不應因 viewport 設定而縮小成桌面版比例。
- 觸控按鈕可啟動所有主要功能。
- 能取得前鏡頭影像並進行姿勢辨識。
- 按鈕尺寸適合手指操作，且不會被手機安全區域遮住。

### 12.4 截圖驗收

- 按下 `P` 或點選「截圖」後能下載 JPG。
- 截圖中的畫面方向應為正向，不應左右反轉。
- 截圖左上角應包含產生時間。

## 13．目前限制與後續建議

1. 任務二目前可在中途站起後重新蹲下，重新開始計時；若需求是「連續維持」，需額外加入失敗判定。
2. 手機直向畫面下，部分固定座標文字可能較小，後續可改成依畫布比例動態配置。
3. 可加入姿勢可信度門檻，降低側身、遮擋或多人入鏡造成的誤判。
4. 可加入開始、暫停與重新開始按鈕。
5. 可加入本機成績紀錄或雲端排行榜。
6. 可將 MediaPipe 模型改為本機部署，降低 CDN 或網路中斷的影響。
