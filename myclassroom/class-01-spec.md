## 1. 文件資訊

| 項目 | 內容 |

| 目前版本 | 1.2 |
| 文件日期 | 2026-09-02 |
| 實作檔案 | `class-01.html` |

| 資料儲存 | 瀏覽器 `localStorage` |

## 2. 系統目的

提供教師快速登記班級常規資料，依日期、學生與登記類別進行查詢、統計、刪除與 CSV 備份。系統不需要後端伺服器，可直接以瀏覽器開啟 HTML 檔案使用。

## 3. 使用對象與權限

### 3.1 使用對象

- 教師：登記學生常規、檢視當日狀況與統計報表。
- 班級管理者：管理學生名單、登記類別、系統名稱與外觀設定。

### 3.2 管理帳號驗證

系統設定提供管理帳號與密碼設定。完成設定後，以下操作必須先通過管理員登入：

- 學生點名登記。
- 資料刪除、清除與完全重設。
- 學生名單與登記類別管理。
- CSV 完整記錄匯出與匯入。
- 統計資料匯出。

首次執行預設管理帳號為 `abc`，預設密碼為 `1234`。進入「系統設定」前也必須先通過管理員登入。建立或修改管理帳號同樣需要先登入。密碼不以明文儲存，系統只保存雜湊結果；登入狀態僅維持於目前頁面工作階段，重新整理頁面後需重新登入。若忘記密碼，單機版沒有遠端重設機制，需由具備資料管理能力的人員處理瀏覽器資料或執行系統重設。

## 4. 執行環境

- 支援現代瀏覽器，例如 Chrome、Edge、Firefox、Safari。
- 支援桌面、平板與手機尺寸。
- 介面使用 Tailwind CSS、Font Awesome 與 Google Fonts 的 CDN 資源。
- 若完全離線，資料功能仍可運作，但外部字型、圖示或部分樣式可能回退至瀏覽器預設樣式。

## 5. 系統功能

### 5.1 看板

功能說明：依指定日期顯示各登記類別的學生資料。

功能需求：

1. 使用者可選擇查詢日期。
2. 只顯示該日期有登記資料的類別。
3. 顯示每個類別的登記總次數。
4. 顯示學生姓名、座號與該類別的登記次數。
5. 可直接刪除指定學生在指定日期及類別的全部記錄。
6. 沒有資料時顯示空白狀態提示。

### 5.2 資料登記

功能說明：教師選擇類別後，點擊學生卡片完成登記。

功能需求：

1. 可選擇登記日期。
2. 可選擇登記類別，例如：作業、秩序、午餐、打掃、值日生。
3. 可依學生姓名或座號搜尋。
4. 學生卡片顯示座號、姓名與目前日期／類別的登記次數。
5. 點擊學生後新增一筆記錄。
6. 登記成功後顯示「已登記：座號＋姓名」提示。
7. 最近記錄顯示座號、姓名、類別、日期與時間。
8. 可刪除最近記錄中的單筆資料。
9. 同一學生、同一天、同一類別允許多次登記。

### 5.3 統計報表

功能說明：依日期區間產生學生及類別統計表。

功能需求：

1. 可選擇開始日期與結束日期。
2. 統計資料包含座號、姓名、各類別次數與合計次數。
3. 可點擊欄位標題依座號、姓名、類別或合計排序。
4. 點擊類別數字可開啟該學生的詳細記錄視窗。
5. 詳細記錄視窗顯示日期與時間。
6. 可刪除詳細記錄中的單筆資料。
7. 可刪除指定學生在目前日期區間內的全部記錄。
8. 統計表支援手機橫向捲動。

### 5.4 CSV 匯出與匯入

#### 5.4.1 統計報表 CSV 匯出

由統計頁面的「統計 CSV」按鈕執行，匯出目前日期區間的彙總資料。

欄位格式：

```text
座號,姓名,[各登記類別],總計
```

#### 5.4.2 完整登記記錄 CSV 匯出

由統計頁或設定頁的「記錄 CSV」／「匯出記錄 CSV」按鈕執行，匯出所有原始登記資料。

欄位格式：

```text
記錄ID,學生ID,日期,時間,座號,姓名,類別
```

檔案使用 UTF-8 BOM，確保 Microsoft Excel 開啟中文時不會亂碼。

#### 5.4.3 完整登記記錄 CSV 匯入

由設定頁的「匯入記錄 CSV」按鈕選取檔案。

必要欄位：

- 日期
- 座號
- 姓名
- 類別

選擇性欄位：

- 時間
- 學生 ID
- 記錄 ID

匯入規則：

1. 系統優先使用學生 ID 對應學生。
2. 若沒有學生 ID，則依座號與姓名對應現有學生。
3. 找不到對應學生、日期格式錯誤或類別空白時，該列略過。
4. 已存在相同記錄 ID，或學生、日期、時間、類別完全相同時，視為重複資料並略過。
5. CSV 中出現的新類別會自動加入系統類別清單。
6. 匯入完成後顯示成功匯入與略過的筆數。

### 5.5 系統設定

#### 5.5.1 系統名稱

可修改頁面標題與上方系統名稱。

#### 5.5.2 自訂外觀

可由上方「自訂外觀」按鈕或設定頁開啟面板。

設定項目：

- 網站主題：晴空藍、森林綠、薰衣草紫、夕陽橙。
- 顯示模式：淺色模式、深色模式、跟隨系統。
- 文字大小：`16` 至 `24`，預設 `18`，面板以百分比顯示。
- 緊湊版面：縮小卡片間距與學生卡片內距。
- 恢復預設：恢復晴空藍、淺色、一般版面與預設字級。

#### 5.5.3 登記項目管理

- 新增登記類別。
- 移除登記類別。
- 移除類別時，同步刪除該類別的相關記錄。
- 系統至少保留一個類別，避免無法登記。

#### 5.5.4 學生管理

- 顯示目前學生人數。
- 批次匯入學生名單，格式為「座號,姓名」，一行一筆。
- 移除單一學生。
- 重置為預設學生名單。
- 移除學生時，同步刪除該學生的相關記錄。

#### 5.5.5 危險操作

- 僅清除所有點名記錄。
- 完全重設名單、記錄、類別與系統設定。
- 所有危險操作均需跳出確認視窗。

#### 5.5.6 管理帳號

- 可建立或修改管理帳號與密碼。
- 修改既有帳號前必須先登入目前帳號。
- 可由上方導覽列查看目前登入狀態並登出。
- 登出後若正在設定頁，系統會返回看板，避免未登入者繼續停留在管理畫面。
- 未登入執行受保護操作時，系統顯示登入視窗，登入成功後繼續原操作。

## 6. 資料規格

### 6.1 學生資料 `students`

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `id` | String | 系統產生的學生識別碼 |
| `seatNo` | String | 兩位數座號，例如 `01` |
| `name` | String | 學生姓名 |

### 6.2 登記記錄 `records`

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `id` | String／Number | 記錄識別碼 |
| `sid` | String | 對應學生的 `id` |
| `seatNo` | String | 登記當下的座號 |
| `name` | String | 登記當下的姓名 |
| `cat` | String | 登記類別 |
| `date` | String | `YYYY-MM-DD` 日期格式 |
| `time` | String | `HH:MM` 時間格式 |

### 6.3 類別資料 `categories`

字串陣列，預設值為：

```text
作業、秩序、午餐、打掃、值日生
```

### 6.4 系統設定 `config`

| 欄位 | 型別 | 預設值 | 說明 |
| --- | --- | --- | --- |
| `systemName` | String | 常規點名 | 系統顯示名稱 |
| `fontSize` | Number | 18 | 介面基準字級 |
| `theme` | String | sky | 網站主題 |
| `displayMode` | String | light | 顯示模式 |
| `compact` | Boolean | false | 是否使用緊湊版面 |
| `auth.enabled` | Boolean | true | 是否已啟用管理帳號 |
| `auth.username` | String | abc | 管理帳號名稱 |
| `auth.passwordHash` | String | 1234 的雜湊值 | 管理密碼雜湊值，不保存密碼原文 |

首次執行的預設帳號為 `abc`，預設密碼為 `1234`；使用者登入後可於系統設定修改。

## 7. 瀏覽器儲存規格

| 儲存鍵值 | 內容 |
| --- | --- |
| `cls_stus_v4` | 學生資料 |
| `cls_recs_v4` | 登記記錄 |
| `cls_cats_v4` | 類別資料 |
| `cls_conf_v4` | 系統設定 |

資料只存在目前瀏覽器的本機儲存空間。清除瀏覽器網站資料、使用無痕模式或更換瀏覽器，可能導致資料無法取得，因此應定期匯出完整記錄 CSV 備份。

## 8. 主要操作流程

```text
開啟系統
  ↓
選擇「登記」
  ↓
選擇日期與類別
  ↓
搜尋或點擊學生卡片
  ↓
新增登記記錄並顯示座號／姓名提示
  ↓
於看板檢視當日資料
  ↓
於統計頁選擇期間、查詢、排序或匯出
```

## 9. 非功能需求

### 9.1 易用性

- 主要功能透過上方導覽列切換。
- 登記操作以學生卡片為主，適合觸控操作。
- 刪除操作提供確認訊息或明確的刪除按鈕。
- 字型可調整，提升不同視力需求使用者的閱讀性。

### 9.2 響應式設計

- 桌面版採多欄卡片與統計表格。
- 小螢幕自動改為單欄或可橫向捲動。
- 導覽列與操作按鈕可依視窗寬度調整。

### 9.3 資料安全

- 不將資料傳送至後端或第三方服務。
- 管理密碼只保存雜湊值，登入狀態不保存於 `localStorage`。
- CSV 匯入前會驗證必要欄位與學生對應關係。
- 完整重設只清除本系統使用的四個 `localStorage` 鍵值，不影響其他網站資料。

- [ ] 可在看板依日期查看資料。
- [ ] 可選擇類別並點擊學生完成登記。
- [ ] 登記提示與最近記錄會顯示學生座號。
- [ ] 可刪除單筆、指定期間或全部登記記錄。
- [ ] 統計表可依欄位排序並查看明細。
- [ ] 統計報表可匯出 CSV。
- [ ] 完整登記記錄可匯出 CSV。
- [ ] 完整登記記錄可由 CSV 匯入。
- [ ] 可管理學生與登記類別。
- [ ] 可切換主題、顯示模式、字級與緊湊版面。
- [ ] 手機寬度下無不可操作的水平溢位。
- [ ] 刪除及完全重設操作具有確認機制。
- [ ] 未設定管理帳號時，執行受保護操作會引導至「系統設定」。
- [ ] 已設定管理帳號但未登入時，進入系統設定或執行受保護操作會顯示登入視窗。
- [ ] 正確帳號密碼登入後，原本被暫停的操作會繼續執行。
- [ ] 登出或重新整理頁面後，受保護操作必須再次登入。
- [ ] 錯誤帳號或密碼不可通過驗證，且不會執行受保護操作。

## 11. 已知限制與後續建議

1. 目前沒有雲端同步與跨裝置共用功能。
2. 管理帳號為單機瀏覽器內的基本保護機制，不等同於具備後端驗證的企業級帳號系統；首次執行的預設帳號密碼應於登入後立即修改。
3. 大量資料時，部分統計運算會直接在瀏覽器執行，資料量過大可能影響效能。
4. 建議後續加入 JSON 備份、資料版本升級與匯入前預覽功能。
5. 若需要多人同時使用，建議增加後端資料庫、登入驗證與操作紀錄。
